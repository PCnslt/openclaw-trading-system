## 📌 Overview

OpenClaw is a self-learning trading AI that predicts top market gainers. It blends large
language models (DeepSeek), HuggingFace transformer models, and a continuous learning loop
to surface high-probability movers.

## ✨ Features

- 🧠 **Self-learning loop** — model retrains on its own predictions vs. realized outcomes
- 📈 **Top-gainers prediction** — ranks candidates by probability of outsized moves
- 🤗 **Model ensemble** — DeepSeek + HuggingFace transformers
- ⚙️ **Automated pipeline** — data ingestion → features → inference → evaluation

## 🛠️ Tech Stack

`Python` · `HuggingFace Transformers` · `DeepSeek` · `Pandas` · `NumPy`
